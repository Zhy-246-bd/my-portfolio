# 我的数智编程作品集

这是一个用 **Next.js + Tailwind CSS** 搭建的个人作品集网站，也是我的期末考核作业。

---

## 一、怎么把网站跑起来（每次做作业都要用）

1. 打开终端（VSCode 里按 `` Ctrl + ` ``；或右键项目文件夹 → 在终端中打开）
2. 进入项目文件夹并启动：

   ```bash
   cd D:\数智编程\MyPortfolio
   npm run dev
   ```

3. 打开浏览器访问 <http://localhost:3000> 就能看到网站
4. 停止运行：回到终端，按 `Ctrl + C`

> 小提示：`npm run dev` 开着的时候，改完代码保存，浏览器会自动刷新，不用重启。

## 二、目录结构（文件都放在哪）

```
MyPortfolio/
├── src/
│   ├── app/                    ← 页面：每个文件夹 = 一个网址
│   │   ├── layout.js           ← 全站外壳（导航栏 + 页脚），所有页面共用
│   │   ├── page.js             ← 首页（网址 /）
│   │   ├── globals.css         ← 全站样式（配色、字体）
│   │   ├── about/page.js       ← ① 个人简介与能力（/about）
│   │   ├── works/page.js       ← ② 阶段作业（/works）
│   │   ├── projects/page.js    ← ③ 项目成果（/projects）
│   │   ├── process/page.js     ← ④ 过程证据（/process）
│   │   ├── iterations/page.js  ← ⑤ 迭代记录（/iterations）
│   │   ├── featured/page.js    ← ⑥ 标志性成果（/featured）
│   │   └── reflection/page.js  ← ⑦ 学习复盘（/reflection）
│   ├── components/             ← 可复用的小零件
│   │   ├── NavBar.js           ← 导航栏（手机端自动变成"菜单"按钮）
│   │   ├── Footer.js           ← 页脚（含 AI 辅助说明）
│   │   └── ComingSoon.js       ← 未完成页面的占位牌
│   └── data/                   ← 【内容数据】只改这里，页面自动更新
│       ├── site.js             ← 姓名、简介、邮箱、导航、首页卡片
│       ├── about.js            ← ① 自我介绍、能力清单、学习目标
│       ├── works.js            ← ② 阶段作业列表
│       ├── projects.js         ← ③ 项目成果
│       ├── process.js          ← ④ 过程证据（需求/原型/提示词/版本/问题）
│       ├── iterations.js       ← ⑤ 迭代记录
│       ├── featured.js         ← ⑥ 标志性成果专题
│       └── reflection.js       ← ⑦ 最终学习复盘
├── public/                     ← 图片等静态文件放这里（图片放 public/images/）
└── package.json                ← 项目依赖清单，一般不用动
```

**记住一句话：改文字内容 → 去 `src/data/`；改页面长相 → 去 `src/app/`。**

## 五、⚠️ 安全红线（课程明确要求）

- **绝对不要把 API 密钥、密码写进代码里**，也不要把它们发到网上
- 需要密钥时，放在项目根目录的 `.env.local` 文件里，用 `process.env.变量名` 读取
- `.gitignore` 里已经写了 `.env*`，这类文件不会被上传到 GitHub
- 作品集里不要放身份证号、家庭住址、成绩单等隐私信息
- 如果密钥不小心泄露了，第一件事是去服务商后台把它**作废并重新生成**，而不是只删掉代码

## 六、迭代记录（课程要求：必须持续迭代，不能期末一次性补做）

> 每次改完网站，就在这里加一条。四要素：改了什么 / 为什么改 / 效果如何 / 下一步。
> 按时间顺序往下记，最新的在最下面。**每次提交 Git 之前，先来这里写一条。**
>
> 📌 计划：这些记录之后会搬到 `src/data/iterations.js`，让老师在网站「迭代记录」页上直接看到（现在只写在本文档里，老师浏览网站时看不到）。

### 第 1 次迭代 · 2026-09-28 · 从零搭好网站空壳

- **改了什么**：搭建了项目基础框架。装上 Next.js + Tailwind CSS；建好 `data`（内容数据）和 `app`（页面）分离的目录结构；完成导航栏（手机端可折叠）、页脚、首页和 7 个板块页面。
- **为什么改**：课程要求网站必须有完整结构并持续迭代。先把"骨架"立起来，之后每次只往里填内容，改起来才不会乱。
- **效果如何**：网站在电脑和手机宽度下都能正常显示；8 个页面之间可以互相跳转，没有死链接；姓名、简介等信息集中在一个文件里，改一处全站生效。
- **下一步**：填写真实的个人信息（`src/data/site.js` 里的姓名和邮箱），然后开始做「关于我」和「阶段作业」两页的内容。

### 第 2 次迭代 · 2026-09-29 · 完善个人信息

- **改了什么**：在 `src/data/site.js` 里把姓名改成「张海燕」，邮箱改成我自己的常用邮箱（共 2 行）。
- **为什么改**：第一次搭建时用的是模板占位文字「你的名字」，不换成真实信息就不算我自己的作品。同时也想验证一下"数据和页面分开"这个设计到底管不管用。
- **效果如何**：只改了 1 个文件里的 2 行，首页大标题、导航栏左上角、页脚署名这 3 个地方**同时**更新了，没有动任何页面代码 —— 说明这种结构确实省事，以后改信息不用一页页找。
- **下一步**：开始做「关于我」页的真实内容（自我介绍 + 能力清单），并把第 1 周的作业录入 `src/data/works.js`，让它自动显示在「阶段作业」页上。

### 第 3 次迭代 · 2026-09-29 · 完成「关于我」页

- **改了什么**：把「关于我」页从一块占位牌换成了真实内容，共三块——自我介绍、能力清单、学习目标，另加了联系方式。新建 `src/data/about.js` 专门存放这一页的内容。
- **为什么改**：占位牌上写着"这一页还在建设中"，不能一直空着；而且「个人简介与能力」是课程要求的第一个板块，应该先把内容最确定的一页做出来。内容单独放一个 data 文件，是为了以后调整时不用碰页面代码 —— 这是第 2 次迭代验证过好用的做法，这次继续沿用。
- **效果如何**：能力清单按「熟练 / 会用 / 学习中」三档如实标注，并分成"编程与开发工具"和"AI 工具使用"两类，老师能一眼看清我的真实水平，不用自己判断；还没写的自我介绍会显示成**黄色草稿框**，提醒我这里是空的，不会误把草稿当成品交上去。
- **下一步**：把自我介绍的三段草稿换成我自己的话；然后从第 1 周的作业开始录入 `src/data/works.js`。

### 第 4 次迭代 · 2026-09-29 · 对照评分标准补齐结构

- **改了什么**：拿到课程的详细评分标准后逐条对照，新建了 5 个数据占位文件（项目成果、过程证据、迭代记录、标志性成果、最终复盘），把每个页面**必须包含的要素**做成数据字段；README 加了「课程要求对照表」任务清单。
- **为什么改**：之前只按"要有 7 个板块"搭了空壳，但没有对照每一页必须包含哪些要素。对照后发现两个问题：一是大部分页面还只有占位牌；二是**迭代记录只写在这个文档里，老师在网站上看不到**，而课程要求它必须是网站内容。
- **效果如何**：7 大模块现在每个都有对应的数据文件和明确的字段，填内容时不会漏项；任务清单能随时看出哪项做完了、哪项没开始，也能直接对着它安排下一步。
- **下一步**：按优先级逐页做内容 —— 先做「过程证据」（评分标准里最重要的一页），再做「阶段作业」，并补上「关于我」页缺的「方向」这一项。
